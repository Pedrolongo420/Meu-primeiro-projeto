# Meu Primeiro Projeto em Python: Calculadora

## Sobre o projeto

Este projeto foi desenvolvido como parte dos estudos de Python.
Esse programa recebe números informados pelo usuário e realiza uma operação matemática.

## Como executar

Para executar o programa através do arquivo `.sh`, primeiro dê
permissão de execução:

chmod +x executar.sh

Depois execute:

./executar.sh

## Código Python

O programa utiliza a função `input()` para receber os valores
informados pelo usuário.

Os valores são convertidos para números e utilizados para realizar
a operação matemática.

O resultado é então apresentado na tela utilizando `print()`.

## Arquivos

- `calculadora.py` — código principal do programa.
- `executar.sh` — script responsável por executar o programa.
- `README.md` — documentação do projeto.
